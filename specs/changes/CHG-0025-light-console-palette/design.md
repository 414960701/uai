# 设计决策

1. **画布**：使用云白/浅冷灰作为全局背景，面板保持白色，输入和次级区使用近白蓝灰，
   让聊天正文成为最安静、最清晰的区域。
2. **主色**：使用低饱和蓝表达主要动作、当前导航、Plan 和选中状态；按钮使用白色文字
   和轻微阴影，避免高饱和紫色或灰蓝按钮造成刺眼、禁用态错觉。
3. **状态色**：健康/完成为绿色，运行/信息为蓝色，部分完成为琥珀色，失败/危险为红色；
   状态色只出现在状态徽章、指示点和反馈组件中。
4. **全局一致性**：为侧栏、顶部栏、运行记录、拓扑、扩展、设置、弹层和聊天工作区
   提供最后一层统一覆盖，清除历史深色块，同时不改组件结构和交互逻辑。
5. **可读性**：保留 3px focus ring、清晰边框和高对比正文；暗色仅允许出现在安全脱敏的
   Trace payload 等代码内容中，默认也使用浅色代码面板。

6. **参考风格**：对齐主流 Agent 工作区的白底、轻边界、低对比活动条和浅色 Composer，
   不让侧栏、任务监视器或运行详情抢过对话正文的视觉重心。
