# 对话与控制台表面设计

1. **消息层级**：用户输入靠右使用柔和色气泡；助手回复靠左使用 Agent 图标和无背景正文，
   只在状态变化、错误或执行阶段处使用局部强调。
2. **回复头部**：Agent 名称是主标签，状态改成低对比度状态点/文字，时间放到次级位置；
   Run ID 和“查看运行详情”保留在底部的低强调操作区。
3. **正文投影**：新增纯函数式 `ChatOutput`，按段落、标题、列表、加粗、行内代码做有限
   Markdown 投影；所有内容仍由 React 文本节点渲染，不使用 `dangerouslySetInnerHTML`。
4. **思考过程**：复用 `PublicReasoningPanel` 的事件投影，仅在聊天 compact 形态覆盖为
   无卡片的活动条；详情面板继续保留完整时间线和 Trace 关系。
5. **流式状态**：正文增量继续沿用 `model.delta` 事实源，光标只作为临时视觉提示；运行中
   阶段显示在正文下方，终态后不残留“进行中”样式。
6. **响应式与无障碍**：保留现有 `aria-live`、键盘折叠和 reduced-motion 行为；窄屏时助手
   回复占满可用宽度，用户气泡仍保持右对齐。
7. **全局 chrome**：侧栏、顶部栏、面板、表单、按钮和弹层共享浅色 token；取消大面积深色
   背景和多重阴影，使用细分隔线、14px 左右圆角和一致的 hover/focus 状态；事件 payload
   代码块保留独立的诊断对比度。
