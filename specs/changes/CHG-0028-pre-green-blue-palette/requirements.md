## VISUAL-006 — Indigo action language

WHEN the console renders a primary action, selected navigation item, or selected Agent-chat
state
THE SYSTEM SHALL use the earlier captured indigo family (`#5667d8` primary and `#4c82c9`
informational accent) on cloud-white/cool-gray surfaces.

WHEN the console renders success or healthy state
THE SYSTEM SHALL keep green (`#2f966c`) reserved for that semantic state and SHALL NOT use it
as the primary action color.

WHEN the restored palette is applied
THE SYSTEM SHALL preserve the existing chat scrolling, streaming, Plan, Todo, Choice, Trace,
IME composition, and keyboard interaction behavior.
