## 研究笔记格式

每个新笔记使用 YAML front matter，并至少包含以下部分：

1. `研究问题`：本轮要回答的未决问题；引用已有笔记中已解决的部分，避免重复检索。
2. `复用的已有证据`：笔记路径和仍然适用的结论。
3. `来源与证据等级`：公开 URL、访问日期、官方文档/源码/标准/二手资料的等级。
4. `观察与结论`：事实和推断分开，保留版本、实验性标记和已知限制。
5. `UAI Forge 转译`：对应的自有 spec、ADR、manifest、实现或测试；禁止把第三方
   Agent、Message、Tool 或 Provider 对象写入核心合同。
6. `取舍与风险`：采用、拒绝或延后的理由，以及兼容性/安全/运维影响。
7. `下一步问题`：尚未解决的问题，供后续 Run 直接消费。

## 运行规则

- 只访问公开网页、官方文档、公开源码和标准资料；不访问登录页、私有仓库或凭据。
- 先读本索引和相关笔记，再设计检索问题；只有新增问题、来源或版本变化才新增网络
  访问。已有结论仍有效时引用它，不复制整段内容。
- 单个网页不可用时记录失败和替代公开来源，不让一个来源阻塞本地规范、实现和测试。
- 研究笔记、代码、规范和测试应在同一演进阶段提交；提交信息要能说明研究结论与实现
  之间的关系。不得把 token、cookie、授权头、私密 URL 或环境变量值写入笔记、事件、
  日志、快照或提交。
- 研究完成的证据不是“搜索过”，而是：问题有回答、来源可复核、取舍已记录、UAI
  转译可追踪、实现和自动化测试通过，或明确记录剩余缺口。
