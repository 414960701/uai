# 设计决策

1. **平面主线**：中央对话使用白色阅读面和轻分隔线；用户输入不再使用厚重气泡，助手
   正文、公开活动和产物按垂直阅读顺序排列。
2. **活动三态**：运行中只显示一行低强调活动摘要；终态默认收起公开阶段；用户点击
   后才展开步骤。原始 reasoning 永远不进入产品输出。
3. **任务右轨**：复杂 execute Run 才占用右侧 Task Monitor；Todo 完成项弱化并划线，
   当前项用低饱和蓝强调，Artifacts 与 Skills/MCP 用可折叠分区承载。
4. **Plan 入口**：Plan 是 Composer 的明确运行方式，不是复杂度推断结果。计划卡提供
   “继续规划/修改计划、批准并执行、暂不执行”三个清晰分支。
5. **Choice 卡**：Choice 头部先说明选择语义，选项使用可点击整行和推荐标记，底部
   固定 Skip/Continue；不把选择结果伪装成普通模型文本。
6. **视觉语言**：云白画布、白色正文、低饱和蓝主操作色；绿色只表达成功/完成，
   不用大面积绿色背景代替层级。
